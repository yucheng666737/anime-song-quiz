【怎麼玩】
1. 把這個資料夾整包解壓縮（四個檔案要放在同一個資料夾）。
2. 連上網路。
3. 雙擊「播放遊戲.bat」。
4. 瀏覽器會自動跳出遊戲，選好年份／難度後按「出題！」。
5. 想結束時，把那個黑色命令列視窗關掉即可。

──────────────────────────────────────────────
【它怎麼運作】
- 題目、封面、音檔都是「即時」從 AnimeThemes.moe 這個社群開放資料庫抓的，
  所以遊玩時需要連網，不需要事先下載幾十 GB 的歌。
- 「播放遊戲.bat」會自動找電腦裡的 Python：
    • 有 Python → 啟動一支小型本地伺服器(server.py)，順便當 API 代理，最穩。
    • 沒有 Python → 直接用瀏覽器開 game.html。多數情況也能玩；
      若題目載不出來，多半是瀏覽器的跨域(CORS)限制，
      去 https://python.org 裝好 Python 再跑一次本檔就行。

【顯示語言（日文）】
歌名、動畫標題、選項按鈕、答案揭曉會優先顯示日文：
  • 歌名 → 用 AnimeThemes 的 title_native（日文歌名），沒有就回退羅馬拼音。
  • 動畫標題 → 用日文別名（synonyms），沒有就回退羅馬拼音。
  • 歌手 → AnimeThemes 只存羅馬拼音（例：LiSA、Nana Mizuki），
           沒有日文歌手名欄位，所以這欄維持羅馬拼音。
日文是社群填的，熱門番覆蓋率高，少數冷門番可能仍是羅馬拼音，屬正常現象。
答案揭曉時若日文與羅馬拼音不同，會一併附上羅馬拼音方便對照。

【關於「難易度」】
目前難易度是用「選項數量」來分（3 / 4 / 6 選 1）。
你給的參考圖裡那種「年度 Top 20 熱門動畫」需要『人氣排名』，
而 AnimeThemes 本身沒有人氣欄位。若想做熱門度篩選，做法是：
  1. 去 AniList API（GraphQL，免費）抓某年 popularity 前 N 名的動畫；
  2. 拿它的標題或 MyAnimeList/AniList ID；
  3. 回到 AnimeThemes 比對撈出對應主題曲。
AnimeThemes 的 anime 資料本來就帶有對 AniList / MyAnimeList 的外部對照，
所以兩邊串接不難，之後想加可以從這裡下手。

──────────────────────────────────────────────
【關於 VOCALOID 分頁】
右上角的 VOCALOID 目前是停用狀態。它要改接 VocaDB API
（https://vocadb.net/api/，免費、回傳 JSON）。
注意：VocaDB 不託管音檔本身，只提供 YouTube / niconico 等外部連結，
所以 VOCALOID 模式得用嵌入式播放器，無法像動漫模式那樣串純音檔。
